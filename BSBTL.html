Be strong, be the last

It’s an open-source, multiplayer, game that we developed for the exam of Videogame Design & Programming. The game ranked third in the multiplayer category at New Game Designer 2020 in Milan (ngd.unimi.it).

Description

The player is a car driver, and he has to compete on fantastic circuits with only one goal: to finish last!

Downloads

  • Windows download: BeStrongBeTheLast.zip

Minimum system requirements

  1. OS: Windows 7 SP1+;
  2. Graphics card with DX10 (shader model 4.0) capabilities;
  3. CPU: SSE2 instruction set support.
