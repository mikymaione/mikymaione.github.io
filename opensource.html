Why Open Source?

The use of open source software and technologies represents a strategic choice based on transparency, reliability, and technical quality. Developing and distributing open-source solutions transforms software from a "black box" into a verifiable tool through these core pillars:

  1. Transparency & Trust: Anyone can inspect, verify, and improve algorithms, ensuring security and technical excellence;
  2. Collective Progress: Knowledge becomes a common good, fostering a model where research is shared rather than isolated;
  3. Project Longevity: Public source code protects users from obsolescence and the restrictions of proprietary systems;
  4. Scientific Validation: In critical fields like medicine or mathematical optimization, sharing code is essential for peer review and evolution;
  5. Democratic Technology: Collaboration ensures that technology remains accessible and geared toward solving real-world problems.
